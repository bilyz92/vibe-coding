# Output Formats

## Default page audit

### Summary
- URL
- Site
- Audit type
- Severity snapshot

### Findings
For each finding include:
- Priority
- Observation
- Why it matters
- Recommended action
- Verification check

### Quick wins
- Top 3 next actions

## Content-refresh add-on
Include when relevant:
- Suggested SEO title
- Suggested meta description
- Suggested heading improvements
- Internal links to add
- CTA suggestion

## Technical-fix add-on
Include when relevant:
- Root cause hypothesis
- Minimum safe fix
- Post-fix verification steps
