# cole.edu.vn Rules

## Article expectations
- For “X là gì” pages, answer the definition early.
- Prefer a structure like:
  1. X là gì?
  2. Vì sao quan trọng?
  3. Ứng dụng / ví dụ
  4. Khi nào nên học / dùng?
  5. Câu hỏi thường gặp
- CTA should usually come after meaningful value, not too early.
- Internal links should support topic-cluster growth and course conversion.

## Priority checks
- Title clarity and search-intent fit
- Meta description usefulness
- Intro directly answering the query
- H2 coverage and scanability
- Internal links to adjacent topic pages and course pages
- FAQ/schema opportunities
- GEO readiness: lists, definitions, concise answer blocks, tables when useful
