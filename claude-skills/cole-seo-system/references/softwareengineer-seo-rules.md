# softwareengineer.vn Rules

## Technical/editorial expectations
- Titles and meta descriptions should be stable and not overly long.
- Avoid duplicate H1s caused by template + body content.
- Images must render reliably; placeholders or broken references are regressions.
- Feed/crawl hygiene matters; low-value crawl paths should stay controlled.
- Cached/stale output must be considered before declaring a fix successful.

## Priority checks
- Canonical presence and correctness
- Meta description quality
- H1/H2 sanity
- Image validity and visible rendering
- Feed endpoint behavior
- Cached page symptoms after changes
- Schema consistency across article pages
