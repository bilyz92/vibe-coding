# Verification Checklists

## After content edits
- Page loads successfully
- Title updated as intended
- Meta description present and correct
- H1/H2 structure sane
- Internal links render and resolve
- Images still load correctly
- No visible layout break

## After technical fixes
- Correct status code
- Correct content-type/charset when relevant
- Canonical correct
- No duplicate or missing metadata
- Affected images load
- Feed/robots/sitemap behavior matches target intent
- Cached/stale output has been cleared or ruled out

## After template/UI changes
- Homepage renders cleanly
- Category page renders cleanly
- Representative article page renders cleanly
- Mobile layout still works
- No duplicated nav/footer/header blocks
