## 4. Priority model
### P0
- technical blockers làm hỏng SEO/tracking/publish

### P1
- pillar content
- cluster expansion chính
- tracking visibility blockers
- homepage/category SEO issues

### P2
- support content
- visual backfill
- CTR optimization
- repurpose layer

### P3
- nice-to-have assets
- secondary experiments
- lower-opportunity content

## 5. Weekly update questions
Mỗi tuần chỉ cần trả lời:
1. Website nào đang bị technical blocker?
2. Cluster nào đang tạo authority mạnh nhất?
3. Batch nào đang bị chậm ở khâu nào?
4. Bài nào có tiềm năng refresh cao nhất?
5. Việc quan trọng nhất tuần tới là gì?

## 6. Rule dùng scoreboard
- Scoreboard phải ngắn, nhìn 1 phút là biết trạng thái.
- Chỉ track thứ phục vụ quyết định, không track cho có.
- Nếu có nhiều website, update ít nhất mỗi tuần 1 lần.
- Scoreboard là lớp thực thi, không thay thế docs chiến lược chi tiết.
